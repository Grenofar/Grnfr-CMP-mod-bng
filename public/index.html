GRNFR CPM

Un mod BeamNG.drive pour jouer à plusieurs avec une économie commune : argent, garage de 4 places, annonces entre joueurs, échanges, taxi, bus et serveurs de 4 joueurs où l'on voit les pseudos des autres.

Télécharger le mod (.zip)

Installation

  1. Ne dézippez pas : copiez grnfr-online.zip dans le dossier mods de votre dossier utilisateur BeamNG (Documents/BeamNG/…/mods ou %LocalAppData%/BeamNG/…/current/mods).
  2. Lancez BeamNG.drive, activez GRNFR CPM dans le Gestionnaire de mods, puis lancez une carte en jeu libre.
  3. Appuyez sur O : onglet Compte, créez un compte avec un pseudo unique (obligatoire), puis onglet Serveurs pour rejoindre un serveur (4 joueurs maximum).

Les données envoyées au serveur : e-mail, pseudo, argent, véhicules du garage, carte et position pendant que vous êtes connecté. Rien d'autre.

Héberger votre propre serveur (GRNFR Host CPM)

Un programme séparé (pas encore relié au mod) : relais réseau auto-hébergé, sans limite de joueurs, avec un nom et un mot de passe facultatif. Premier lancement = assistant de configuration ; une page web locale permet de la modifier ensuite. Compilé automatiquement à chaque version par GitHub Actions.
